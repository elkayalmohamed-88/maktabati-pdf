# مكتبتي PDF — My PDF Library

تطبيق ويب تقدمي (PWA) عربي لتنظيم ملفات PDF وقراءتها محليًا على الجهاز. لا يوجد تسجيل دخول أو خادم أو قاعدة بيانات سحابية. تُخزن الملفات وبيانات المكتبة في IndexedDB عبر Dexie.js.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل محليًا
```bash
npm install
npm run dev
```
افتح العنوان الذي يعرضه Vite. قد لا تتوفر كل ميزات PWA إلا عبر `localhost` أو HTTPS.

## بناء نسخة النشر
```bash
npm run build
npm run preview
```
ينتج البناء داخل `dist/`.

## النشر على Vercel
1. ارفع مجلد المشروع إلى مستودع GitHub.
2. في Vercel اختر **Add New → Project** ثم اربط المستودع.
3. Framework Preset: **Vite**، وأمر البناء `npm run build`، ومجلد الإخراج `dist`.
4. انشر الموقع عبر HTTPS.
5. اختبر إضافة كتاب والنسخ الاحتياطي على الهاتف. لا يحتاج المشروع إلى متغيرات بيئة أو قاعدة بيانات.

> ملاحظة: بيانات IndexedDB مرتبطة بالمتصفح/أصل الموقع والجهاز. إذا تغير النطاق، أو حُذفت بيانات المتصفح، أو أُلغي تثبيت التطبيق، فقد لا تبقى البيانات. صدّر نسخة ZIP كاملة بانتظام واحتفظ بها خارج الهاتف.

## الخصوصية والتخزين
- لا ترفع ملفات PDF إلى الإنترنت.
- ملفات الكتب محفوظة في IndexedDB، منفصلة عن Cache API الخاصة بموارد التطبيق.
- JSON يحفظ بيانات المكتبة فقط ولا يحتوي ملفات PDF. ZIP الكامل يضم `library.json` ومجلد `pdfs/`.
- حماية التخزين عبر `navigator.storage.persist()` طلب يقرره المتصفح ولا يضمن منع كل حالات فقدان البيانات.
- عند استعادة ZIP، تحقّق الواجهة من وجود ملف PDF لكل كتاب قبل بدء الاستعادة. خيار الدمج لا يكرر معرفات الكتب الموجودة.

## ميزات مضمّنة
- إضافة ملف PDF وفحص ترويسة الملف ومحاولة تحميله باستخدام PDF.js.
- بيانات العنوان والمؤلف والوصف والقسم، مع أغلفة افتراضية.
- الأقسام: إنشاء وتعديل وإعادة ترتيب وحذف آمن ينقل الكتب إلى «غير مصنف».
- قارئ PDF داخلي، صفحة سابقة/تالية، الانتقال لرقم صفحة، التكبير/التصغير، والعودة لآخر صفحة.
- حفظ التقدم لكل معرف كتاب في IndexedDB مع تأخير قصير للحفظ.
- بحث وفرز وعرض شبكي/قائمة ومفضلة.
- تصدير JSON أو ZIP كامل، واستعادة أو دمج النسخ.
- وضع ليلي/نهاري، إحصائيات تخزين، وطلب حماية التخزين.
- manifest وService Worker وأيقونات PWA.

## حدود معروفة
- يجب تحميل موارد التطبيق أول مرة عبر الإنترنت قبل الاعتماد على التشغيل دون اتصال. يعتمد نجاح فتح التطبيق دون اتصال على المتصفح ونجاح تخزين ملفات البناء في Cache.
- بحث النص داخل PDF غير مضاف في هذه النسخة؛ قارئ PDF يدعم عرض الصفحات والتنقل والتكبير. البحث داخل النص يحتاج واجهة طبقة النص وربطها مع PDF.js.
- قارئ PDF يعرض الصفحة الحالية لتقليل الذاكرة بدل رسم كل الصفحات دفعة واحدة.
- الملفات الكبيرة جدًا تعتمد على سعة IndexedDB والذاكرة المتاحة على الجهاز. راقب صفحة التخزين واحتفظ بنسخ احتياطية.
- التحقق من التوافق الكامل على أجهزة فعلية يتطلب اختبارات يدوية على Android وiOS ومتصفحات مختلفة.

## نتائج الفحص
- تم إعداد بنية المشروع وملفات المصدر وملفات PWA.
- شغّل `npm install` ثم `npm run build` للتحقق من البناء في بيئتك.
- لم تُجرَ اختبارات فعلية على هاتف حقيقي في هذه الحزمة، لذلك لا تُعدّ هذه الملاحظة شهادة باجتياز جميع الاختبارات الستة عشر المطلوبة.
